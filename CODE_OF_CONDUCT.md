# Code of conduct

This is a place to learn and to compare how different languages solve the same problems. To keep it that way:

- Be respectful and assume good faith. Disagree with the idea, not the person.
- Be specific and kind in review: say what is wrong and what would make it right.
- No harassment, discrimination, personal attacks, or publishing other people's private information.
- Questions are welcome, including basic ones.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block someone who keeps doing so.
To report a problem with someone's behaviour, use a [private security advisory](https://github.com/dsimonov762/wallpaperhub-template/security/advisories/new) and say it is about conduct; only the maintainer can see it.
